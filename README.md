# ⚙️ GEARGRID — Modern Mechanic & Auto Service Login Portal

A sleek, responsive, and high-performance **Login & Sign-Up Interface** designed for mechanics, auto repair shops, and garage management systems. Built with **HTML5**, **CSS3**, and **Bootstrap 5**, featuring smooth pure-CSS transitions between authentication states.

---

## ✨ Features

- **🏎️ Automotive Aesthetic:** Dark-themed UI with high-contrast electric amber accents.
- **🔄 Dynamic Switcher:** Smooth sliding transition between **Login** and **Sign Up** forms (Pure CSS).
- **📱 Fully Responsive:** Adaptive layout optimized for Desktop, Tablets, and Mobile devices.
- **🔤 Modern Typography:** Styled with Google Fonts (`Rajdhani` for headers & `Inter` for body text).
- **🌐 Accessible & Lightweight:** Clean semantic HTML structure with FontAwesome vector icons.

---

## 🛠️ Tech Stack

* **HTML5** — Semantic document structure
* **CSS3** — Custom properties, animations, and layouts
* **Bootstrap 5** — Responsive grid system and utility classes
* **Font Awesome 6** — Modern icon assets
* **Google Fonts** — *Rajdhani* & *Inter* typography

---

## 🚀 Quick Start

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/laizoo-dev/geargrid-login-portal.git](https://github.com/laizoo-dev/geargrid-login-portal.git)
   ```

2. **Navigate to project directory:**
    ```bash
    cd geargrid-login-portal
    ```
3. **Launch the app:**
    Open `index.html` directly in your browser, or run a local web server (e.g., Live Server extension in VS Code).

   **📂 Project Structure**

    ```
    ├── index.html     # Main markup containing Login & Sign Up forms
    ├── style.css      # Custom styling, root variables, and switcher animations
    └── README.md      # Project documentation
    ```
